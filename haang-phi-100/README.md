# ห้างผี ๑๐๐ คืน (Haang Phi 100 Nights)

เกม 3D เอาชีวิตรอด 100 วันในป่าไทย — กลางวันล่าสัตว์หาเสบียง กลางคืนนั่งห้างบนต้นไม้ใหญ่สู้ผีไทย
(กระสือ, ผีปอบ, ผีโขมด, เสือสมิง, ผีพราย, ผีกระหัง, เปรต, บอส นางตะเคียน)

- ติดตั้ง: `HaangPhi100.apk` (Android 7.0+, แนวนอน)
- ตัวเกม: `app/src/main/assets/game/` (three.js + WebGL, เสียงสังเคราะห์ด้วย WebAudio)
- Build: `gradle assembleDebug` (ต้องมี Android SDK 34) หรือดู GitHub Actions `haang-phi-apk.yml`
- ทดสอบบนคอมได้: เปิด `app/src/main/assets/game/index.html` ผ่าน http server (WASD + เมาส์)
