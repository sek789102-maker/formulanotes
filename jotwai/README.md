# จดไว้ (Jotwai)

แอปจดโน้ตทั่วไปสำหรับ Android ภาษาไทย ทำงานออฟไลน์ทั้งหมด ไม่มีบัญชี ไม่มีโฆษณา ไม่ขอสิทธิ์อินเทอร์เน็ต

- Package: `com.sek789102.jotwai` · minSdk 24 · targetSdk 36
- Kotlin, Jetpack Compose (Material 3), Room, DataStore, WorkManager, Glance widget

## ฟีเจอร์
- โน้ตข้อความแบบเห็นผลทันที (ซ่อนเครื่องหมาย): ตัวหนา เอียง ขีดเส้นใต้ ขีดฆ่า, สีตัวอักษร/สีไฮไลต์ (25+20 สี + เลือกสีเองได้ทุกสี),
  ขนาดตัวอักษร 6–160 (ปุ่ม A−/A+ และแถบเลื่อน), ฟอนต์ 5 แบบ, ตัวยก/ตัวห้อย, โค้ด, หัวข้อ 3 ระดับ, รายการจุด/ตัวเลข/ช่องติ๊ก,
  ข้อความอ้างอิง, จัดชิดซ้าย/กลาง/ขวา/เต็มบรรทัด, เพิ่ม/ลดย่อหน้า, เส้นคั่น, แทรกวันเวลา, ล้างรูปแบบ, ต่อรายการอัตโนมัติเมื่อกด Enter
  (เก็บเป็นข้อความ + แท็ก ⟦…⟧ ใน `domain/RichText.kt` จึงค้นหา/สำรอง/ประวัติ/แชร์ได้เหมือนเดิม)
- โน้ตแบบรายการ (Checklist): ติ๊กแล้วย้ายลงหมวด “เสร็จแล้ว”, กดค้างลากเพื่อจัดลำดับ, แปลงข้อความ ⇄ รายการ
- รูปจากกล้อง/คลังรูป, วาดรูป, ดูรูปแบบซูมได้
- สีโน้ต 12 สี, ปักหมุด, เก็บถาวร, ถังขยะ 30 วัน (เลิกทำได้ทันที)
- โฟลเดอร์ + ป้ายกำกับ (หลายป้ายต่อโน้ต)
- การเตือนตามเวลา ทำซ้ำรายวัน/สัปดาห์/เดือน/ปี, ปุ่ม “เสร็จแล้ว” และ “เลื่อน 10 นาที” ในการแจ้งเตือน
- ค้นหาทั้งหัวเรื่อง เนื้อหา รายการ และป้ายกำกับ + ตัวกรองสี/รายการ/มีรูป/มีการเตือน
- เลิกทำ/ทำซ้ำในหน้าแก้ไข และ **ประวัติการแก้ไข** (เก็บเวอร์ชันก่อนหน้า 30 เวอร์ชันต่อโน้ต กู้คืนได้)
- ล็อกโน้ตด้วยล็อกหน้าจอ/ลายนิ้วมือของเครื่อง (ซ่อน ไม่ได้เข้ารหัส)
- มุมมองตาราง/รายการ, เรียงตามแก้ไข/สร้าง/ชื่อ, เลือกหลายโน้ตพร้อมกัน
- รับข้อความ/รูปที่แชร์มาจากแอปอื่น, แชร์โน้ตออก, ทำสำเนา
- วิดเจ็ตหน้าจอหลัก, ทางลัดไอคอนแอป (โน้ตใหม่/รายการใหม่)
- สำรอง/กู้คืนเป็น .zip (รองรับไฟล์จากแอป “สมุดโน้ตสูตร” เดิม)
- ธีมสว่าง/มืด/ตามระบบ, สีตามวอลเปเปอร์, ขนาดตัวอักษร 4 ระดับ

## Build
ต้องใช้ JDK 21 และ Android SDK (เปิดโฟลเดอร์นี้ใน Android Studio ได้เลย) โปรเจคไม่มี `gradlew` ใช้ Gradle 9.3.1

```
gradle :app:testDebugUnitTest   # เทสต์
gradle :app:assembleDebug       # APK ทดสอบ
gradle :app:bundleRelease       # AAB (ไม่เซ็นถ้าไม่ได้ตั้ง keystore)
```

การเซ็น release อ่านจาก environment variables เท่านั้น: `KEYSTORE_PATH`, `STORE_PASSWORD`, `KEY_PASSWORD`, `KEY_ALIAS` — ห้าม commit keystore/รหัสผ่าน
