# Store listing — ช่างคำนวณ

**App name (27/30):**
```
ช่างคำนวณ: วัสดุ ใบเสนอราคา
```

**Short description (≤80):**
```
คำนวณอิฐ ปูน คอนกรีต กระเบื้อง สี เหล็ก แล้วส่งใบเสนอราคาทาง LINE ไม่มีโฆษณา
```

**Full description:**
```
ช่างคำนวณ — เครื่องมือของช่างและผู้รับเหมาไทย คำนวณวัสดุที่ต้องซื้อ แล้วออกใบเสนอราคาส่งลูกค้าได้ในไม่กี่แตะ ไม่มีโฆษณา ใช้ออฟไลน์ที่หน้างานได้

🧱 คำนวณวัสดุ บอกจำนวนที่ต้องซื้อจริง
• ก่ออิฐ: อิฐมอญ (ครึ่งแผ่น/เต็มแผ่น) อิฐมวลเบา คอนกรีตบล็อก — หักประตูหน้าต่างให้
• ฉาบปูน: ตามความหนาและจำนวนด้าน
• เทคอนกรีต: พื้น คาน เสา ฐานราก — ผสมเสร็จ (สั่งเป็นคิว) หรือผสมเอง 1:2:4, 1:1.5:3, 1:3:6
• ปูกระเบื้อง: จำนวนกล่อง กาวซีเมนต์ ยาแนว เผื่อเศษให้
• ทาสี: สีจริง + รองพื้น คิดเป็นถังและแกลลอน
• เหล็กเส้น: จำนวนเส้น และน้ำหนัก (RB6–DB25)
• ปัดเป็นหน่วยที่ร้านขายจริง: ถุง ก้อน กล่อง คิว ถัง เส้น

📄 ใบเสนอราคามืออาชีพ
• รวมรายการวัสดุ ค่าแรง ค่าใช้จ่ายอื่น ในแต่ละงาน
• ค่าดำเนินการ/กำไร % ส่วนลด ภาษีมูลค่าเพิ่ม 7% และหัก ณ ที่จ่าย 3%
• ยอดรวมเป็นตัวอักษรภาษาไทย ช่องเซ็นชื่อ เลขที่ใบเสนอราคา
• ส่งเป็นรูปภาพทาง LINE หรือเป็น PDF
• แสดงชื่อร้านและข้อมูลของคุณเท่านั้น

💰 ราคาวัสดุของคุณเอง
• ใส่ราคาจากร้านที่ซื้อจริง ครั้งเดียว ใช้ได้ทุกงาน

⚙️ ปรับสูตรได้
• ค่าเริ่มต้นจากตารางปริมาณวัสดุมาตรฐาน แก้ได้ทุกค่า พร้อมบอกที่มา

📐 แปลงหน่วย ตร.ม. ↔ ตร.วา งาน ไร่ ฟุต นิ้ว คิว ลิตร

🔒 ไม่มีโฆษณา ไม่มีป๊อปอัป ไม่ต้องสมัครบัญชี ไม่ขอสิทธิ์ใดๆ ข้อมูลอยู่ในเครื่องคุณ และสำรอง/ย้ายเครื่องได้

หมายเหตุ: ปริมาณวัสดุเป็นค่าประมาณ ควรเผื่อตามหน้างาน งานโครงสร้างให้ใช้ตามแบบวิศวกร
```
