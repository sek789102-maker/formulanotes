# Store listing — ช่างคำนวณ

**App name (27/30):**
```
ช่างคำนวณ: วัสดุ ใบเสนอราคา
```

**Short description (≤80):**
```
คำนวณวัสดุงานช่าง-โยธา 27 แบบ ออกใบเสนอราคา ใบแจ้งหนี้ ใบเสร็จ BOQ
```

**Full description:**
```
ช่างคำนวณ — เครื่องมือของช่าง งานโยธา และผู้รับเหมาไทย คำนวณวัสดุที่ต้องซื้อ ออกเอกสารให้ลูกค้า แบ่งงวดเบิกเงิน และดูกำไรต่องาน ใช้ออฟไลน์ที่หน้างานได้

🏗️ งานโครงสร้าง
• เทคอนกรีต: พื้น คาน เสา — ผสมเสร็จ หรือผสมเอง 1:2:4, 1:1.5:3, 1:3:6
• ฐานราก + ตอม่อ · เสาเข็มตอก / เข็มเจาะ · บันได (ลูกตั้ง ลูกนอน ตรวจเกณฑ์ให้)

🔩 งานเหล็ก และไม้แบบ
• เหล็กเส้น · เหล็กเสริมตามระยะ (พื้น คาน เสา เหล็กปลอก ลวดผูก) คิดการตัดเหล็กให้
• เหล็กรูปพรรณ: H-beam ตัวซี เหล็กกล่อง ท่อ แผ่น — น้ำหนักต่อเมตร
• ไม้แบบ: ไม้อัด ไม้เคร่า ค้ำยัน ตะปู คิดการใช้ซ้ำ

🧱 งานก่อ ฉาบ ผนัง สี · 🏠 พื้น ฝ้า หลังคา
• ก่ออิฐ ฉาบปูน ผนังเบา ทาสี ปูกระเบื้อง ปูพื้น SPC/ลามิเนต ฝ้ายิปซัม/ทีบาร์ หลังคากระเบื้อง/เมทัลชีท

🚜 งานดิน และงานโยธาภายนอก
• ขุดดิน ถมดิน ดินตัด-ถมจากระดับ กำแพงกันดิน — จำนวนเที่ยวรถ
• ถนนคอนกรีต (หินคลุก ไวร์เมช เหล็กเดือย) · ท่อระบายน้ำ + บ่อพัก · งานลาน · รั้ว

🚰 งานระบบ และเครื่องมือ
• งานท่อ PVC · ถังบำบัด / ถังเก็บน้ำตามจำนวนคน · ความลาดเอียง % องศา 1:n · แปลงหน่วย

📄 เอกสารผู้รับเหมา
• ใบเสนอราคา ใบแจ้งหนี้ ใบเสร็จรับเงิน (ทั้งงาน หรือรายงวด) และ BOQ แยกหมวด
• ภาษีมูลค่าเพิ่ม 7% หัก ณ ที่จ่าย 3% ยอดเงินเป็นตัวอักษรไทย ช่องเซ็นชื่อ
• ส่งเป็นรูปทาง LINE, PDF หรือไฟล์ Excel (CSV)

💼 บริหารงาน
• แบ่งงวดงาน (มัดจำ / ตามความคืบหน้า) ติดตามยอดรับแล้ว-ค้างรับ
• บันทึกค่าแรงรายวัน ค่าวัสดุ ค่าใช้จ่ายหน้างาน — ดูกำไรต่องานทันที
• รายการสั่งของรวมทุกการคำนวณ ส่งให้ร้านวัสดุทาง LINE

💰 ราคาวัสดุของคุณเอง · ⚙️ ปรับอัตราการใช้วัสดุได้ทุกค่า พร้อมบอกที่มา

🔒 ไม่ต้องสมัครบัญชี ไม่ขอสิทธิ์ใดๆ ข้อมูลอยู่ในเครื่องคุณ สำรอง/ย้ายเครื่องได้

หมายเหตุ: ปริมาณวัสดุเป็นค่าประมาณเพื่อสั่งของและตั้งงบ ไม่ใช่การออกแบบโครงสร้าง งานโครงสร้างให้ใช้ตามแบบวิศวกร
```
