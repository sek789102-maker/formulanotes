# Release notes — 1.2.1 (versionCode 7)

ใช้ช่อง "Release notes" ใน Play Console (≤500 ตัวอักษรต่อภาษา)

```
<th-TH>
จดไว้ 1.2.1 โฉมใหม่ ดำทอง
• หน้าหลักใหม่: สรุปโน้ต รายการโปรด โฟลเดอร์ และโน้ตล่าสุด
• แท็บการแจ้งเตือน และแท็บโฟลเดอร์ เลือกสีโฟลเดอร์ได้
• ตั้งค่า: ธีมมืด/สว่าง ขนาดตัวอักษร เปิดปิดการเตือน
• ส่งออก/นำเข้าโน้ตเป็นไฟล์ .txt
• รองรับภาษาอังกฤษ
• แก้ปัญหารหัสจัดรูปแบบโผล่ในโน้ต และไอคอนใหม่
</th-TH>
<en-US>
Jotwai 1.2.1: new black-and-gold look
• New home: note counts, favourites, folders, recent notes
• Reminders tab and folders tab with folder colours
• Settings: dark/light theme, text size, reminders on/off
• Export/import notes as .txt files
• English language
• Fixed formatting codes showing in notes; new icon
</en-US>
```

## เวอร์ชันแรก — 1.0.0 (versionCode 1)

ใช้ช่อง "Release notes" ใน Play Console (≤500 ตัวอักษรต่อภาษา)

```
<th-TH>
เวอร์ชันแรกของ "จดไว้"
• โน้ตข้อความจัดรูปแบบได้ และรายการติ๊กถูก
• รูปภาพ วาดรูป สีโน้ต ปักหมุด เก็บถาวร
• โฟลเดอร์และป้ายกำกับ ค้นหาทั้งเนื้อหา
• ตั้งเตือนและเตือนซ้ำได้
• เลิกทำ ประวัติการแก้ไข ถังขยะ 30 วัน
• ล็อกโน้ต วิดเจ็ต สำรองและกู้คืน
ใช้งานออฟไลน์ ไม่มีโฆษณา ไม่ต้องสมัครบัญชี
</th-TH>
<en-US>
First release of Jotwai
• Formatted text notes and checklists
• Photos, drawing, colours, pin, archive
• Folders, labels and full-text search
• Reminders with repeat
• Undo, version history, 30-day trash
• Locked notes, widget, backup and restore
Offline, no ads, no account.
</en-US>
```
