# Store listing — จดไว้ (Jotwai)

## ภาษาไทย (th-TH) — ภาษาหลัก

**App name (≤30) — 28 ตัวอักษร:**
```
จดไว้: โน้ต รายการ แจ้งเตือน
```

**Short description (≤80) — 73 ตัวอักษร:**
```
จดโน้ต ทำรายการ ตั้งเตือน ค้นหาไว ใช้ออฟไลน์ ไม่มีโฆษณา ไม่ต้องสมัครบัญชี
```

**Full description (≤4000) — 1,894 ตัวอักษร:**
```
จดไว้ คือแอปจดโน้ตที่เรียบง่าย เร็ว และเป็นส่วนตัว ทุกอย่างอยู่ในเครื่องของคุณ ไม่มีบัญชี ไม่มีโฆษณา และแอปไม่ขอสิทธิ์ใช้อินเทอร์เน็ต

✏️ จดได้ทุกแบบ
• โน้ตข้อความ จัดรูปแบบได้: ตัวหนา ตัวเอียง ขีดฆ่า ไฮไลต์ หัวข้อ รายการแบบจุดและตัวเลข
• กด Enter แล้วรายการต่อให้อัตโนมัติ
• รายการ (Checklist) ติ๊กแล้วย้ายไปหมวด "เสร็จแล้ว" กดค้างลากเพื่อจัดลำดับ
• เปลี่ยนโน้ตข้อความเป็นรายการ และกลับได้ในแตะเดียว
• แนบรูปจากกล้องหรือคลังรูป และวาดรูปด้วยนิ้ว

⏰ ไม่ลืมอีกต่อไป
• ตั้งเตือนในโน้ต เลือกเร็ว ๆ ได้ (เย็นนี้ พรุ่งนี้เช้า สัปดาห์หน้า) หรือกำหนดวันเวลาเอง
• เตือนซ้ำทุกวัน ทุกสัปดาห์ ทุกเดือน หรือทุกปี
• กด "เสร็จแล้ว" หรือ "เลื่อน 10 นาที" จากการแจ้งเตือนได้ทันที
• การเตือนยังอยู่ครบหลังรีสตาร์ตเครื่อง

🗂️ จัดระเบียบง่าย
• สีโน้ต 12 สี ปักหมุดโน้ตสำคัญไว้ด้านบน
• โฟลเดอร์ และป้ายกำกับ (ติดได้หลายป้ายต่อโน้ต)
• เก็บถาวรโน้ตที่ไม่ใช้แล้วโดยไม่ต้องลบ
• มุมมองแบบตารางหรือรายการ เรียงตามแก้ไขล่าสุด สร้างล่าสุด หรือชื่อ
• เลือกหลายโน้ตพร้อมกัน เพื่อปักหมุด เปลี่ยนสี ย้าย หรือลบ

🔍 หาเจอเสมอ
• ค้นหาทั้งหัวเรื่อง เนื้อหา รายการ และป้ายกำกับ รองรับภาษาไทย
• กรองตามสี รายการ มีรูป หรือมีการเตือน

🛟 ไม่กลัวข้อมูลหาย
• บันทึกอัตโนมัติขณะพิมพ์
• เลิกทำ / ทำซ้ำ ขณะแก้ไข
• ประวัติการแก้ไข: เก็บเวอร์ชันก่อนหน้าให้อัตโนมัติ กู้คืนได้
• ลบแล้วกด "เลิกทำ" ได้ทันที และถังขยะเก็บไว้ 30 วัน
• สำรองและกู้คืนทั้งหมด (โน้ต รูป โฟลเดอร์ ป้ายกำกับ) เป็นไฟล์ .zip

🔒 เป็นส่วนตัว
• ล็อกโน้ตด้วยลายนิ้วมือ ใบหน้า หรือล็อกหน้าจอของเครื่อง (โน้ตที่ล็อกจะถูกซ่อน)
• ใช้งานออฟไลน์ทั้งหมด ไม่มีบัญชี ไม่มีโฆษณา ไม่มีการติดตาม

✨ สะดวกทุกที่
• วิดเจ็ตหน้าจอหลัก แสดงโน้ตที่ปักหมุดและปุ่มจดโน้ตใหม่
• ทางลัดจากไอคอนแอป: โน้ตใหม่ / รายการใหม่
• แชร์ข้อความหรือรูปจากแอปอื่นเข้ามาเป็นโน้ตได้ทันที และส่งโน้ตออกไปได้
• ธีมสว่าง มืด หรือตามระบบ สีตามวอลเปเปอร์ (Android 12+) และปรับขนาดตัวอักษรได้

หมายเหตุ: โน้ตที่ล็อกถูกซ่อนไว้หลังล็อกหน้าจอ แต่ไม่ได้เข้ารหัส และไฟล์สำรองไม่ได้เข้ารหัส ควรเก็บไฟล์สำรองไว้ในที่ปลอดภัย
```

## English (en-US) — optional translation

**App name:** `Jotwai: Notes, Lists, Reminders`

**Short description:**
```
Notes, checklists and reminders. Fast, offline, private. No ads, no account.
```

**Full description:**
```
Jotwai is a simple, fast and private note app. Everything stays on your phone: no account, no ads, and the app does not even request internet access.

• Text notes with bold, italic, strikethrough, highlight, headings and lists (lists continue when you press Enter)
• Checklists: ticked items move to a "Done" section; long-press and drag to reorder
• Photos from camera or gallery, and finger drawing
• Reminders with quick choices or a custom date and time; repeat daily, weekly, monthly or yearly; "Done" and "Snooze 10 min" right from the notification
• 12 note colours, pin, archive, folders and labels
• Search titles, text, checklist items and labels, with filters
• Autosave, undo/redo, automatic version history, trash with undo (kept 30 days)
• Full backup and restore as a .zip file
• Lock notes with your fingerprint, face or screen lock (locked notes are hidden, not encrypted)
• Home-screen widget, app shortcuts, share text and photos into new notes
• Light, dark or system theme, wallpaper colours (Android 12+), adjustable text size
```
