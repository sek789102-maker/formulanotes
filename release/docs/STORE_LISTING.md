# Google Play Store Listing — LIFEKEEP (ภาษาไทย)

> ตรวจความยาวตามข้อจำกัดของ Play แล้ว (ตัวเลขด้านล่าง) · ข้อความทั้งหมดตรงกับฟีเจอร์ที่มีจริงในเวอร์ชัน 1.0.0

## App name (≤ 30)
LIFEKEEP: เอกสาร งาน ปฏิทิน

## Short description (≤ 80)
เก็บเอกสารสำคัญ งาน และนัดหมาย พร้อมแจ้งเตือน ออฟไลน์ 100% ข้อมูลอยู่ในเครื่อง

## Full description (≤ 4000)
LIFEKEEP ช่วยจัดการเรื่องสำคัญในชีวิตประจำวันไว้ในที่เดียว ทั้งเอกสาร งาน และกำหนดการ โดยทุกอย่างทำงานในเครื่องของคุณ ไม่ต้องสมัครบัญชี ไม่ต้องใช้อินเทอร์เน็ต และไม่มีโฆษณา

📁 เอกสารสำคัญ
• เก็บบัตรประชาชน ใบขับขี่ กรมธรรม์ หนังสือเดินทาง และเอกสารอื่น ๆ
• แนบรูปได้หลายรูปจากแกลเลอรีหรือกล้อง ดูรูปเต็มจอและซูมได้
• ตั้งวันหมดอายุ แจ้งเตือนล่วงหน้า 1, 3, 7 วัน หรือกำหนดเอง
• หมวดหมู่ ปักหมุด ค้นหา กรอง และเรียงลำดับ มุมมองแบบรายการหรือตาราง

✅ งาน
• กำหนดวัน เวลา ความสำคัญ และหมวดหมู่
• แบ่งเป็น วันนี้ / ถัดไป / เลยกำหนด / เสร็จแล้ว
• ปัดเพื่อทำเสร็จหรือลบ พร้อมปุ่มเลิกทำ

📅 ปฏิทิน
• มุมมองรายเดือนและรายสัปดาห์
• แสดงกิจกรรม งาน และวันหมดอายุเอกสารในที่เดียว
• กิจกรรมทั้งวันหรือหลายวัน พร้อมสถานที่และการแจ้งเตือน

🔔 การแจ้งเตือนในเครื่อง
• แจ้งเตือนงาน กิจกรรม และเอกสารใกล้หมดอายุ
• ทำงานแบบออฟไลน์ (ความตรงเวลาขึ้นกับการตั้งค่าแบตเตอรี่ของ Android)

🔒 ความเป็นส่วนตัว
• แอปไม่มีสิทธิ์เข้าถึงอินเทอร์เน็ต ข้อมูลไม่ถูกส่งออกจากเครื่อง
• ล็อกแอปด้วย PIN หรือลายนิ้วมือ/ใบหน้า และซ่อนเนื้อหาจากหน้าแอปล่าสุด
• ไม่มีบัญชี ไม่มีการติดตาม ไม่มีโฆษณา

💾 สำรองและกู้คืนข้อมูล
• สำรองเป็นไฟล์ ZIP (JSON + รูปภาพ) พร้อมตรวจสอบความถูกต้องด้วย checksum
• บันทึกไฟล์สำรองไปยังตำแหน่งที่คุณเลือก เช่น USB หรือคอมพิวเตอร์
• สำรองอัตโนมัติรายวันหรือรายสัปดาห์ในเครื่อง
• กู้คืนแบบแทนที่หรือรวมข้อมูลโดยไม่ซ้ำ และย้อนกลับอัตโนมัติหากเกิดข้อผิดพลาด

✨ อื่น ๆ
• ภาษาไทยและอังกฤษ · ธีมสว่าง มืด หรือตามระบบ
• ค้นหาทุกอย่างได้จากที่เดียว

หมายเหตุ: ข้อมูลเก็บในเครื่องเท่านั้น หากถอนการติดตั้งแอป ข้อมูลจะถูกลบ กรุณาสำรองข้อมูลไปเก็บภายนอกเป็นประจำ ไฟล์สำรองไม่ได้เข้ารหัส
